# UI: Блок "Отзывы" специалиста

Компонент: `frontend/components/specialist/SectionReviews.tsx`.

## Источник данных
Используется `specialist_public_review` (массив `reviews`).

## Карточка отзыва
Каждая карточка содержит:
- `author_name`
- `content`

## Логика отображения
- Если отзывов нет (или после нормализации не осталось валидных) — секция не рендерится.
- Если отзывов несколько — рендерится список карточек отзывов.

## Безопасность
Перед отображением `author_name` и `content` проходят sanitization:
- удаляются `<script>...</script>`
- удаляются inline-обработчики (`on*`)
- удаляются `javascript:` payload
