# UI: Hero блок страницы специалиста

## Цель
Верхний блок страницы формирует доверие: показывает фото специалиста, цитату и быстрый CTA.

## Структура
- Левая колонка: фото специалиста.
- Правая верхняя ячейка: `hero_quote`.
- Правая нижняя ячейка: кнопка `Связаться со специалистом`.

## Верстка
В компоненте `frontend/components/specialist/Hero.tsx` используется Grid со схемой:
- `photo | quote`
- `photo | button`

## Поведение при отсутствии quote
Если `hero_quote` отсутствует, блок остается валидным и продолжает рендериться без падения.

## Безопасность
Изображения рендерятся только с разрешенных доменов (`images.mbot.app`, `cdn.mbot.app`).
Для неразрешенного или некорректного URL показывается безопасный плейсхолдер вместо `<img>`.
