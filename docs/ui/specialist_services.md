# UI: Блок "Услуги и цены" специалиста

Компонент: `frontend/components/specialist/SectionServices.tsx`.

## Источник данных
Используется `specialist_public_block` с `block_type = services`.

## Логика отображения
- Если блок отсутствует — секция не рендерится.
- Если блок присутствует — рендерится список услуг.
- Поддерживаются форматы:
  - массив элементов (`items`)
  - строка из `content/body/text` с разделением по переводам строк

## Отображение услуги
Каждая строка показывает:
- название услуги
- цену (если указана)

## Безопасность
Текст проходит sanitization перед отображением:
- удаляются `<script>...</script>`
- удаляются inline-обработчики (`on*`)
- удаляются `javascript:` payload
