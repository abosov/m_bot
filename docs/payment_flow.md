# Payment flow

## Checkout page before YooKassa payment

Перед переходом в YooKassa пользователь открывает страницу `https://zumbot.ru/pay?token=...`.

На этой странице пользователь видит описание сервиса Zumbot, выбранный тариф, период подписки, стоимость и кнопку перехода к оплате.

Оплата выполняется **на сайте zumbot.ru (/pay)** с последующим перенаправлением на защищенную страницу YooKassa, а не внутри Telegram.

## Payment moderation compliance

Для модерации платежей важно разделение ролей каналов:
- оплата выполняется на сайте, на странице `zumbot.ru/pay`;
- Telegram-бот используется только для помощи с выбором тарифа и формирования ссылки;
- сама платежная страница и подтверждение оплаты размещены на домене `zumbot.ru`.
