# Deployment (VPS)

Краткая и актуальная инструкция по ручному деплою находится в runbook:

- [`docs/runbook_vps.md`](./runbook_vps.md)

Используйте только её как источник истины, чтобы избежать расхождений.

## Docs decision: куда встроены эксплуатационные утилиты

Новые эксплуатационные инструменты и правила git-гигиены встроены в существующие
документы без создания новых `*.md`:

- **Краткая запись (навигация/обзор):** `README.md`.
- **Операционная инструкция (команды и шаги):** `docs/runbook_vps.md`.
- **Назначение и ограничения:**
  - по media cleanup/check — `docs/security/media_storage.md`;
  - по dev-cleanup — `docs/test_data_reset.md`;
  - по git-мусору и ignore-политике — `README.md` (с отсылкой к `.gitignore`).

Причина: эти разделы уже являются точками входа для эксплуатации (VPS runbook),
безопасности хранения медиа (security) и локальных reset/clean процедур
(test data reset), поэтому отдельный новый документ не требуется.
