Политика конфиденциальности — Zumbot

Дата вступления в силу: 18 февраля 2026 г.

Zumbot — Calendar Booking Automation — это сервис автоматизации записи встреч, интегрированный с Google Calendar API.

Какие данные мы получаем

После авторизации через Google OAuth 2.0 пользователь предоставляет Zumbot доступ к своему Google Calendar.

Мы можем получать доступ к следующим данным:

  • события календаря
  • время начала и окончания событий
  • название события
  • описание события
  • статус занятости (free/busy)

Как используются данные Google

Данные Google используются исключительно для:

  • создания событий календаря
  • изменения событий календаря
  • удаления событий календаря
  • проверки занятости календаря для предотвращения пересечений

Мы НЕ используем данные Google:

  • для рекламы
  • для маркетинговых целей
  • для перепродажи
  • для передачи третьим лицам
  • для анализа вне основной функциональности сервиса

Хранение и защита данных

Zumbot хранит только минимально необходимую техническую информацию для работы сервиса.

Мы не сохраняем полный архив календаря пользователя.

OAuth-токены хранятся в защищённой серверной среде и используются исключительно для выполнения действий по прямому запросу пользователя.

Передача третьим лицам

Мы не продаём, не передаём и не раскрываем данные пользователей Google третьим лицам.

Срок хранения данных

Данные хранятся только пока пользователь активно использует сервис.

При отзыве доступа через настройки Google-аккаунта или по запросу пользователя соответствующие токены и связанные данные удаляются.

Удаление данных

Пользователь может:

  • отозвать доступ по ссылке https://myaccount.google.com/permissions
  • запросить удаление данных по email: abosov@gmail.com

Соответствие политике Google

Использование и передача информации, полученной через Google API, соответствует Google API Services User Data Policy, включая требования Limited Use.

Коммерческая модель сервиса

Zumbot работает по модели подписки (SaaS). Оплата взимается исключительно за доступ к функциональности автоматизации записи.

Пользователь сохраняет полное право собственности на свои данные Google.

Данные Google не продаются, не лицензируются, не передаются третьим лицам и не используются как коммерческий актив.

Доход сервиса формируется исключительно за счёт подписки на функциональность, а не за счёт использования или анализа данных Google.
