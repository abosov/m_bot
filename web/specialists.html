Для специалистов

Простой запуск без технической команды — всё настраивается за несколько шагов.

1. Подключите Telegram

Нажмите «Подключить» и авторизуйте аккаунт специалиста.

2. Настройте расписание

Выберите рабочие часы, длительность сессии и перерывы.

3. Принимайте записи

Клиенты бронируют время сами, а бот ведёт их по сценарию.
