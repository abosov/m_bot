Privacy Policy — Zumbot

Effective Date: February 18, 2026

Zumbot — Calendar Booking Automation — is a meeting scheduling service integrated with the Google Calendar API.

Data We Access

After authorization via Google OAuth 2.0, users grant Zumbot access to their Google Calendar.

We may access the following data:

  • calendar events
  • event start and end times
  • event titles
  • event descriptions
  • free/busy status

How Google Data Is Used

Google data is used strictly for:

  • creating calendar events
  • updating calendar events
  • deleting calendar events
  • checking calendar availability to prevent scheduling conflicts

We do NOT use Google data:

  • for advertising
  • for marketing purposes
  • for resale
  • for transfer to third parties
  • for analysis outside core service functionality

Data Storage and Protection

Zumbot stores only the minimum technical data required to operate the service.

We do not store a full archive of a user’s calendar.

OAuth tokens are stored in a secure server environment and used only to perform actions explicitly requested by the user.

OAuth tokens are encrypted at rest and in transit. Access to stored data is restricted to authorized system processes required for service operation. We implement reasonable technical and organizational security measures to protect user data.

Third-Party Sharing

We do not sell, share, or disclose Google user data to third parties.

Data Retention

Data is retained only while the user actively uses the service.

When access is revoked via Google Account settings or upon user request, associated tokens and related stored data are deleted.

Data Deletion

Users may:

  • revoke access at https://myaccount.google.com/permissions
  • request data deletion via email: abosov@gmail.com

Compliance with Google Policies

Zumbot’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, which prohibit transferring or selling Google user data except as necessary to provide and improve the service’s core functionality.

We do not use Google user data for artificial intelligence model training, profiling, advertising, or any purpose unrelated to the core functionality of the service.
