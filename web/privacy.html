Политика конфиденциальности Zumbot

Zumbot — это сервис автоматизации записи встреч с использованием Google Calendar API.

Какие данные мы получаем

После согласия пользователя мы получаем доступ к данным Google Calendar, необходимым для:

  • создания событий
  • изменения событий
  • удаления событий
  • проверки занятости календаря

Мы не сохраняем содержимое календаря пользователя за пределами технически необходимого для работы сервиса.

Использование данных

Данные Google используются исключительно для предоставления функциональности записи встреч.

Мы:

  • не передаём данные третьим лицам
  • не продаём данные
  • не используем данные в рекламных целях

Хранение данных

Данные хранятся только в объёме, необходимом для работы сервиса.

Отзыв доступа

Пользователь может в любой момент отозвать доступ через:

https://myaccount.google.com/permissions
